Configure Groq API Key

Set up your free individual API key to unlock the AI DSA Tutor

Step-by-step Setup Instructions:

  1. 1
    Visit console.groq.com/home and sign in with your Google or GitHub account (or create a new account).
  2. 2
    Click on "API Keys" in the top navigation bar, or go directly to console.groq.com/keys.
  3. 3
    Click the "+ Create API Key" button. Enter a Display Name of your choice (e.g. PyChamp-DSA) and select your preferred expiration timeline. Complete any identity verification and click Submit. Note: You can revisit the Groq Console at any time when your key expires to generate a fresh one.
  4. 4
    Your API Key will be revealed once. Copy it to your clipboard immediately and paste it into the field below.
Free Tier & Rate Limits Disclaimer

PyChamp runs open-source models on Groq's free tier, which provides zero token cost to you. However, to avoid encountering temporary rate-limit errors, please use the AI DSA Tutor within moderate request frequencies. To learn more about usage quotas, review the Groq Rate Limits documentation.

Your API key is stored securely in your individual user profile and is only used to execute your AI agent queries.
